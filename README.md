# 長期上昇候補スクリーナー（ローカル実行版）

株探(kabutan.jp)のデータをもとに、業績（ファンダメンタルズ）・株価トレンド（テクニカル）・
需給（信用取引）を組み合わせて「長期で上昇しやすそうな候補」をスコアリングするツールです。

これまでClaude(このリポジトリの元になった会話)が毎回スクレイピングと計算を代行していましたが、
その部分をこのローカルスクリプトに肩代わりさせ、**計算済みの結果（output/summary_latest.json）を
Claudeとの会話に貼ってコメントをもらう**運用に切り替えるためのものです。

## 必要なもの

- Windows / macOS / Linux のいずれか
- Python 3.9 以上（<https://www.python.org/> からインストール可能。インストール時に
  「Add Python to PATH」にチェックを入れてください）
- インターネット接続（kabutan.jpにアクセスできること）

## 使い方（Windows）

1. このフォルダを好きな場所に置く
2. `run.bat` をダブルクリック
   - 初回は仮想環境(venv)の作成と依存パッケージのインストールが走るので少し時間がかかります
   - 実行が終わると `output/report.html` が自動でブラウザに開きます
3. `output/summary_latest.json` の中身をコピーして、Claudeとの会話に貼り付けると
   上位銘柄や前回からの変化についてコメントをもらえます（ファイルをそのまま添付してもOK）

## 使い方（macOS/Linux）

```bash
./run.sh
```

## 出力物

| パス | 内容 |
|---|---|
| `output/report.html` | ブラウザで見るランキング表＋実行ログ（毎回上書き） |
| `output/summary_latest.json` | Claudeに貼って確認してもらう用の要約（上位20銘柄＋前回との比較） |
| `data/screener.db` | SQLite。実行のたびに履歴を蓄積（削除しない限り消えません） |
| `data/raw_pages/` | デバッグ用に、取得した生HTMLを保存（トラブル時の確認用） |

## 信用取引（需給）データのキャッシュ

候補銘柄1件ごとに個別ページ(`kabutan.jp/stock/?code=...`)を取得して信用取引データを
読みに行きますが、信用残は株探でも**週次**でしか更新されないため、毎回180件超すべてを
取り直すのは非効率です。そこで `data/screener.db` 内に `credit_cache` テーブルを持ち、
**取得から6日以内のデータはキャッシュを再利用**して株探への再アクセスをスキップします
（`kabutan_screener/config.py` の `CREDIT_CACHE_MAX_AGE_DAYS` で日数は変更可能）。

実行のたびにコンソールと`output/report.html`に「キャッシュ利用○件／新規取得○件」が
表示されるので、どれくらい節約できたか確認できます。信用残が更新されたはずなのに
反映されない、といった場合は次のようにキャッシュを無視して全銘柄を再取得できます。

```bash
python screener.py --refresh-credit
# または
run.bat --refresh-credit   (Windows)
./run.sh --refresh-credit  (macOS/Linux)
```

なお、ファンダメンタルズ／テクニカルのランキング一覧（候補選定そのもの）は
日々の株価で順位が変わるため、こちらは毎回取得し直します。

## スコアの算出方法

各指標を候補銘柄集団内でのパーセンタイル順位（0〜100点、高いほど良い）に変換し、
以下の重みで合成しています（Claudeとの会話で決めた方式と同じです）。

- **ファンダメンタルズ 40%**: 連続増益期数35% + 今期予想増益率40% + 増益期間平均増益率25%
- **テクニカル 35%**: 25日線カイリ率25% + 75日線カイリ率35% + 200日線カイリ率40%
- **割安度 10%**: PERの低さ（低いほど加点）
- **需給 15%**: 信用倍率（信用買い残÷売り残、低いほど加点）。売り残ゼロの
  「買い長」銘柄は、直近の信用買い残の増減率から
  `max(15, min(65, 50 - 増減率(%)×0.5))` で代替評価します。

候補条件: 通期営業利益が3期以上連続増益 **かつ** 25日・75日・200日移動平均線が
すべて上向き（両方のランキングに共通して登場する銘柄のみ）。

## kabutan.jpのページ構成が変わった場合

このスクリプトはCSSのクラス名ではなく、**見出しセルの文字列**（「コード」「銘柄名」
「株価」など）を手がかりにテーブルを探すようにしてあるため、多少のレイアウト変更には
耐えられるはずです。それでも動かない場合は:

1. `data/raw_pages/` に保存された生HTMLを開いて、実際の見出し文字列を確認する
2. `kabutan_screener/scraper.py` の `*_HEADER_ALIASES` に、実際の見出し文字列を追加する
3. `output/report.html` の実行ログや、コンソールに表示されるエラーメッセージも手がかりになります

わからない場合は、そのエラーメッセージと `data/raw_pages/` の該当HTMLをClaudeに見せて
相談してください。

## 定期実行したい場合

Windowsのタスクスケジューラに `run.bat` を登録すれば、毎日決まった時間に自動実行できます
（このリポジトリ自体には自動実行の仕組みは含めていません。手動 or お好みのスケジューラで
実行してください）。
